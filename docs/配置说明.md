# 配置说明

项目使用两类配置：普通配置放在根目录 `config.toml`，秘密放在根目录 `.env`。
Python 启动时由 `app/settings.py` 统一读取和校验；修改后需要重启服务。操作系统已有的
环境变量优先于 `.env` 中的同名值。

## Google 表格普通配置

配置段为 `[google_sheets]`。

| 配置 | 默认值 | 含义 | 约束 |
| --- | --- | --- | --- |
| `gid` | `0` | 目标工作表的数字 ID | 非负整数 |
| `poll_interval_seconds` | `5` | 接收开启时，两轮检查之间的秒数 | 大于 0 |
| `batch_size` | `100` | 单次最多读取的数据行数 | 1～500 |
| `request_timeout_seconds` | `30` | 单次网关请求超时秒数 | 大于 0 |
| `enabled_on_startup` | `false` | 服务启动时是否自动打开接收 | TOML 布尔值 |

`enabled_on_startup` 默认关闭，通过配置文件控制，修改后重启生效。不提供 FastAPI
开关接口，不自动监听文件变化。关闭时不请求网关、不启动接收线程。
设为 `true` 后，每次启动先调用 `tail`，在内存记录当时的表格末尾；此前的行和
关闭期间新增的行都不补入库。取得末行失败时启动报错，不会宣称已开启。

## 清库测试与恢复步骤

同步模块已接入 `main.py`，操作步骤如下：

1. 将 `enabled_on_startup` 改为 `false` 并保存。
2. 正常停止旧 Python 服务，等待“Google 表格接收已停止，当前批次已结束”。
3. 重新启动服务，确认日志“Google 表格接收已关闭”，再清空 `leads`、添加测试客户。
4. 恢复时改为 `true`，正常停止并重启服务；从此刻表格末尾之后接收新增行。

仅保存配置不会立即停止正在运行的接收。开关只控制 Google 数据同步，重启整个
Python 服务会同时重启其中其他模块；关闭接收后的其他客户处理模块仍可运行。

## Google 表格秘密配置

| 环境变量 | 含义 | 校验 |
| --- | --- | --- |
| `GOOGLE_APPS_SCRIPT_URL` | 已部署的 Apps Script Web 应用地址 | 必须是 `https://script.google.com/macros/s/.../exec` |
| `GOOGLE_APPS_SCRIPT_TOKEN` | 与脚本属性 `ACCESS_TOKEN` 相同的访问令牌 | 开启时必填，至少 32 个字符；关闭时可留空 |
| `MYSQL_PASSWORD` | MySQL 密码 | 开启时必填；关闭时可留空 |

`[mysql]` 配置段保存 `host`、`port`、`user`、`database` 和 `connection_timeout`。
当前指向 2026-09-12 新建的新系统专用库 `lintratek_AI`（旧系统的 `lintratek_chat` 不再使用、
不受影响），连接超时为 10 秒。真实密码只在 `.env` 填写，不写入日志。
每批入库创建并关闭数据库连接，使用严格 SQL 模式，只有重复主键跳过，其他错误回滚。

## 启动命令

首次联系相关配置已增加：

| 配置段 | 配置 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `wa_bridge` | `base_url` | `http://127.0.0.1:3010` | Python 调用 WhatsApp 桥的地址 |
| `wa_bridge` | `request_timeout_seconds` | `60` | 单次请求等待时间，大于 0 且不超过 300 秒 |
| `first_contact` | `enabled_on_startup` | `false` | 是否启动自动首次联系；不影响 Google 同步 |
| `first_contact` | `poll_interval_seconds` | `20` | 每轮完成后等待秒数，大于 0 且不超过 86400 |
| `first_contact` | `batch_size` | `20` | 每轮最多线索数，1～500 |

配置保存后重启 Python 才生效。首次联系开启后会扫描所有未联系线索。
发送超时不表示一定失败，不自动重发；遇到不确定发送或发送后落库失败会停止扫描并记错误日志。
应人工核对该 lead 后再重启。两个接收/联系开关目前都保持 false，等待测试 lead。


在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

服务监听本机 8000 端口。使用 Ctrl+C 正常停止；不同时启动多个实例或多个 Uvicorn worker，
否则会各自运行同步。没有新增 FastAPI 开关接口。`main.py` 会显示接收状态、同步统计与脱敏错误。
默认关闭时不会连接网关或数据库；开启时先获取表格末行，下一批开始读取新行。

真实 `.env` 已被 `.gitignore` 排除。`.env.example` 只提供字段示例，不得写入真实令牌。
启动日志如需展示配置，应调用 `safe_summary()`，它只显示令牌已经配置，不显示令牌内容。
