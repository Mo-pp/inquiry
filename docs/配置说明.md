# 配置说明

项目使用两类配置：普通配置放在根目录 `config.toml`，秘密放在根目录 `.env`。
Python 启动时由 `app/settings.py` 统一读取和校验；修改后需要重启服务。操作系统已有的
环境变量优先于 `.env` 中的同名值。

## Google 表格普通配置

配置段为 `[google_sheets]`。

| 配置 | 默认值 | 含义 | 约束 |
| --- | --- | --- | --- |
| `gid` | `0` | 目标工作表的数字 ID | 非负整数 |
| `poll_interval_seconds` | `5` | 接收开启时，两轮检查之间的秒数 | 大于 0 |
| `batch_size` | `100` | 单次最多读取的数据行数 | 1～500 |
| `request_timeout_seconds` | `30` | 单次网关请求超时秒数 | 大于 0 |
| `enabled_on_startup` | `false` | 服务启动时是否自动打开接收 | TOML 布尔值 |

`enabled_on_startup` 默认关闭。后续实现运行时开关后，每次打开接收都会先调用网关的
`tail`，以内存记录当时的表格末尾；此前的行和关闭期间新增的行都不补入库。这个配置
只决定服务启动时是否自动执行该“打开”操作，不控制后续客户联系模块。

## Google 表格秘密配置

| 环境变量 | 含义 | 校验 |
| --- | --- | --- |
| `GOOGLE_APPS_SCRIPT_URL` | 已部署的 Apps Script Web 应用地址 | 必须是 `https://script.google.com/macros/s/.../exec` |
| `GOOGLE_APPS_SCRIPT_TOKEN` | 与脚本属性 `ACCESS_TOKEN` 相同的访问令牌 | 必填，至少 32 个字符 |

真实 `.env` 已被 `.gitignore` 排除。`.env.example` 只提供字段示例，不得写入真实令牌。
启动日志如需展示配置，应调用 `safe_summary()`，它只显示令牌已经配置，不显示令牌内容。
